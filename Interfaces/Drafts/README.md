# Drafts Directory

Working space for synthesizing fragments into coherent documentation before final publication.

## Purpose

- Draft SOPs, runbooks, and guides
- Combine scattered notes into structured documents
- Collaborate on documentation before it goes live
- Test formatting and content flow

## Workflow

1. Start with fragments from Bridge Zone summoning
2. Create draft document here
3. Tag reviewers and iterate
4. Move final version to appropriate `/docs/` location
5. Update any Bridge Zone logs with final links

## Naming Convention

- `YYYY-MM-DD_topic_draft.md` for dated drafts
- `topic_v1_draft.md` for versioned iterations
- Include `_REVIEW` suffix when ready for feedback
