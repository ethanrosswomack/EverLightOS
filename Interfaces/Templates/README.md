# Templates Directory

Standard templates for EverLight OS documentation and processes.

## Available Templates

- **Council_Log_Template.md** - Standard format for council session documentation
- Cross-references the [Council Table](../Council_Table.md) for seat assignments
- Used by `bridge_zone_summon.py` and manual session logging

## Usage

Copy templates to appropriate directories when starting new documentation or processes. Templates include placeholders for:

- Session metadata (timestamps, sigils, invokers)
- Council seat participation tracking
- Context snapshots and git status
- Action checklists and follow-up tasks
- Convergence artifact tracking
