# Bridge Zone Logs

Auto-generated logs from `bridge_zone_summon.py` that capture convergence moments and synthesis intentions.

## Structure

```
Bridge_Zone_Logs/
├── YYYY/
│   ├── MM/
│   │   ├── DD/
│   │   │   ├── HHMMSSZ_bridge_zone_<sigil>.md
│   │   │   └── ...
```

## Purpose

Each log represents a deliberate "Bridge Zone" - a moment where scattered knowledge converges into actionable next steps. These logs serve as:

- Audit trail of synthesis decisions
- Context snapshots for future reference  
- Action checklists to drive completion
- Sigil-based unique identification

## Usage

Logs are created automatically but should be updated manually as work progresses:

1. Complete the action checklist items
2. Add links to fragments and drafts
3. Update with final outcomes
4. Commit with the suggested message format
